# ⚡ Campus Memory OS

> An anti-boring digital memory box and retro-OS dashboard for the chaotic first-year campus experience. 

Built for the Vibeathon. 

---

## ✨ Features
* **Retro-Futuristic Terminal UI:** Designed for midnight coding sessions, terminal aesthetics, and maximum visual appeal.
* **Living Campus Radar:** Live insights, hack-meet alerts, lab coordinates, and the constant threat of hostel curfews.
* **Year 1 Timeline Stream:** Tracks real micro-milestones like your first Linux workstation setup, design sprints, and initial Git commits.
* **College DNA Breakdown:** Visual metrics mapping out technical, leadership, research, and creative stats.

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Typography:** Geist Font Family
* **Deployment:** Vercel

## 🚀 Getting Started

Clone the repository and spin up the development server:

```bash
